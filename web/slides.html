04 / THE CORE · 6 MIN

Agent Loop：循环是关键

01 用户任务提出问题
02 模型推断选择下一步
03 工具调用结构化参数
04 工具执行可信的计算
05 结果反馈决定继续还是结束

LLM 提出行动，Runtime 实际执行，工具结果再回到上下文。

Tool Calling 不是模型自己执行 JavaScript 或 SQL。模型只能调用被授权的工具。
05 / TOOLS · 4 MIN

给 Agent 一双可控的手

const tool = {
name: "analyze_data",
description: "分析南京统计数据",
parameters: { /* JSON Schema */ },
execute: async (_, args) => {
return querySQLite(args);
}
};
01name / description：告诉模型能做什么
02parameters：限定调用参数
03execute：由应用代码执行操作
04白名单：拒绝任意 SQL / Shell
