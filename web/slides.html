DESIGN 03 / TOOL CONTRACT

工具设计：先规划，再执行

list_datasetsinspect_datasetanalyze_datacreate_chartquery_weather
查询工具契约名称 + 描述 + Schema + 白名单

指标必须在数据目录内；聚合方式枚举；模型只选参数，不写查询语句。

规划工具 · 本系统特色submit_plan / update_plan

先提交需求分析与步骤清单才能动数据工具；执行中实时打勾；每问重新规划。

规划是结构约束：钩子拦截 + 状态重置，而不是提示词里的“请先计划”。
